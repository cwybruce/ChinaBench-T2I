# Capability Taxonomy

ChinaBench-T2I V0.1 暂定 8 个核心能力维度。

| ID | 能力 | 核心问题 |
|---|---|---|
| C1 | Subject Recognition | 指定对象是否准确出现 |
| C2 | Counting | 数量是否准确 |
| C3 | Attribute Binding | 颜色、材质等是否绑定到正确对象 |
| C4 | Spatial Relation | 左右、前后、上下等空间关系是否准确 |
| C5 | Action Relation | 谁对谁执行什么动作是否准确 |
| C6 | Composition | 多主体、多动作、多对象能否同时成立 |
| C7 | Chinese Text | 中文文字、位置、方向是否准确 |
| C8 | Cultural Accuracy | 中国文化对象、仪式、器物、语义是否准确 |

## 难度分层

### Level 1：原子能力

单对象、单属性、简单计数。

### Level 2：双变量组合

例如：

- 红兔 + 白马
- 兔在虎左侧
- 三兔两虎

### Level 3：关系与反事实

例如：

- 兔骑虎
- 鸡划龙舟
- 猴刺绣牡丹

### Level 4：多约束组合

同时要求对象、数量、属性、动作、空间和中文文字。

### Level 5：中国文化理解

要求模型不仅识别物体，还必须理解中国文化中的正确形式与关系。

## 十二生肖 × 能力矩阵

后续题库应尽量避免某个生肖只承担单一能力。

目标是让每个生肖在不同版本中跨越多个维度，防止结果被“某种动物本身更好画”这一因素主导。
