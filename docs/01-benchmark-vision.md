# Benchmark Vision

## 1. 项目定位

ChinaBench-T2I 不是“中国风图片审美榜”，而是一套以中国文化为测试载体的文生图能力 Benchmark。

核心问题不是：

> 哪个模型画得最好看？

而是：

> 哪个模型最准确地理解并执行了复杂视觉指令？

## 2. 为什么使用十二生肖

十二生肖天然构成一个稳定的 12 主体集合：

鼠、牛、虎、兔、龙、蛇、马、羊、猴、鸡、狗、猪。

优势：

- 主体边界清晰
- 文化辨识度高
- 外形差异明显
- 可与动作、属性、位置、数量形成大量组合
- 适合构造反事实和低共现组合
- “龙”等主体可检测中国文化理解与西方视觉先验冲突

## 3. Benchmark 设计原则

### 3.1 先定义能力，再设计题目

不从“有趣 Prompt”出发，而从能力缺口出发。

### 3.2 每道题尽量对应可判定事实

例如：

> 白兔坐在黑马上，手持红灯笼，灯笼写“福”。

可拆为多个原子条件，而不是给一个模糊的“像不像”。

### 3.3 破坏统计捷径

优先设计：

- 罕见组合
- 关系反转
- 属性错配高风险组合
- 文化知识与视觉先验冲突
- 长 Prompt 中的相互干扰条件

例如：

- 兔骑虎
- 鸡划龙舟
- 猪写毛笔字
- 猴刺绣
- 中国龙参加舞龙表演

这些题的价值不在“搞笑”，而在于迫使模型真正解析主体—动作—对象关系。

### 3.4 视觉质量和正确性分离

一张非常漂亮但主体、数量、关系错误的图，不应获得高 Benchmark 分数。

### 3.5 保留长期 Anchor Questions

Anchor Questions 固定不变，用于跨模型、跨版本观察能力演进。
