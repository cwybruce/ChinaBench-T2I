# ChinaBench Scoring System

## 总分结构

| 维度 | 权重 |
|---|---:|
| Instruction Following | 20 |
| Object / Counting | 15 |
| Attribute Binding | 10 |
| Spatial Relationship | 10 |
| Action Relationship | 10 |
| Chinese Text | 15 |
| Cultural Accuracy | 15 |
| Visual Quality | 5 |
| **Total** | **100** |

## 核心原则

### 1. 原子评分优先

每题拆成若干可验证条件。

例：

> 白兔坐在黑马上，手里拿红灯笼，背景是长城，灯笼写“福”。

可以拆成：

| 条件 | 分值 |
|---|---:|
| 出现兔 | 1 |
| 兔为白色 | 1 |
| 出现马 | 1 |
| 马为黑色 | 1 |
| 兔骑在马上 | 2 |
| 兔手持灯笼 | 1 |
| 灯笼为红色 | 1 |
| 背景为长城 | 1 |
| “福”字正确 | 1 |

总分 10。

### 2. 强约束项允许更高权重

关系、文字、文化准确性等更容易暴露模型真实能力，可高于单纯对象存在。

### 3. 不用“整体感觉不错”代替评分

除 Visual Quality 外，所有主要分数应尽量有明确判定依据。

### 4. 错误不能被美感抵消

例如：

- 题目要求兔骑虎，模型画成虎追兔
- 题目要求 3 只兔，模型画 5 只
- 题目要求中国龙，模型画成带翅膀西方龙

即使画面精美，也应明确扣除对应能力分。
