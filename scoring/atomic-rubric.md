# Atomic Rubric

## 原子条件类型

### O — Object

对象是否存在、对象类型是否正确。

### N — Number

数量是否准确。

### A — Attribute

颜色、材质、服饰、形态是否绑定到正确对象。

### S — Spatial

左右、上下、前后、内外、远近等空间关系。

### R — Relation / Action

主体、动作、客体关系。

### T — Text

字符内容、字序、位置、方向、排版。

### C — Culture

文化元素、器物、仪式、造型、场景关系是否符合中国文化语境。

### V — Visual

构图、清晰度、完成度、审美。

## 推荐题目格式

每道正式题应记录：

- Question ID
- Prompt CN
- Prompt EN（可选）
- Capability Tags
- Difficulty
- Atomic Conditions
- Total Score
- Expected Failure Modes
- Cultural Notes
- Anchor: true / false
- Version
