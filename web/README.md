# ChinaBench-T2I Web Viewer

The V0.1 web UI is a static, explainable benchmark viewer for all 30 tests.

## Canonical routes

- Results overview: `web/results/index.html`
- Shared case viewer: `web/results/case.html?id=CB-001`
- Legacy routes such as `web/results/CB-001.html` redirect to the shared viewer and preserve the selected test ID.

## Evidence separation

The viewer has two deliberately separate modes:

- **SPEC ILLUSTRATION** — HTML/CSS/SVG schematic showing what the prompt asks and how the atomic rubric is structured. It is never model evidence.
- **MODEL OUTPUT** — the real generated image, when one exists. Official scoring can only be based on this evidence.

Pending runs show neutral atomic states and `— / 10`. A numeric score appears only after atomic review is complete.

## Data flow

The browser loads the authoritative benchmark and run data directly:

- `benchmark/v0.1/questions.json`
- `benchmark/v0.1/anchors.json`
- `results/chatgpt-image/run-2026-10-06.json`
- `web/data/scene-specs-v0.1.json`

`web/data/cases-v0.1.json` is a derived validation/build artifact generated by `scripts/build-viewer-data.mjs`; it is not a second source of truth.

## Local validation

```bash
node --test tests/*.test.mjs
node scripts/build-viewer-data.mjs
node scripts/validate-viewer.mjs web/data/cases-v0.1.json
```

GitHub Actions runs the same checks before Pages deployment.
