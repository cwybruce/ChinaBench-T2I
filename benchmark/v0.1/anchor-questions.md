# Anchor Questions — V0.1

Anchor Questions 用于跨模型、跨时间长期复测，原则上发布后不轻易修改。

## 候选 A1：兔骑虎

**目标：** Action Relation / Compositional Generalization

> 一只白兔骑在一只黑色老虎背上，白兔右手提着写有“福”字的红灯笼，正在穿过一座传统中式牌楼。

重点检测：

- 兔与虎均准确出现
- 兔是骑乘者，虎是被骑乘者
- 白兔 / 黑虎属性绑定
- 红色灯笼
- “福”字
- 中式牌楼

## 候选 A2：中国龙 vs 西方龙

**目标：** Cultural Accuracy

> 一支春节舞龙队正在表演传统中国舞龙，一条长身无翼的中国龙由多人持杆操控。

重点检测：

- 中国龙形态
- 无西式巨大翅膀
- 舞龙杆
- 多人共同操控
- 春节场景

## 候选 A3：鸡划龙舟

**目标：** Action Relation / Culture

> 一只公鸡站在龙舟上划桨，船头有一只猴子击鼓，背景为端午节河岸。

## 候选 A4：猴刺绣

**目标：** Rare Composition / Tool Use

> 一只猴子坐在传统苏绣绣架前，用针线刺绣一朵牡丹。

## 候选 A5：十二生肖全家福

**目标：** Object Recall / Counting / Culture

> 十二生肖鼠、牛、虎、兔、龙、蛇、马、羊、猴、鸡、狗、猪各出现一次，围成完整圆环，传统剪纸风格。

## 候选 A6：中文春联

**目标：** Chinese Text / Layout

> 中式宅院大门贴着红色春联：上联“春风入户”，下联“喜气盈门”，横批“万事如意”。
