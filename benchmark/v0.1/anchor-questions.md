# Anchor Questions — V0.1

Anchor Questions 用于跨模型、跨时间长期复测，原则上发布后不轻易修改。

统一规则：

- 每题满分 10 分。
- 先逐项打 Atomic Score，再汇总。
- 没有实际生成图，不给正式分数。
- 当前默认评分模型：GPT-5.6 Sol。
- 当前 ChatGPT 生图结果展示时，生成模型写作：ChatGPT Image Generation (exact model undisclosed)。

## A1｜兔骑虎

**Test ID：** CB-A01  
**目标：** Action Relation / Attribute Binding / Chinese Text / Cultural Object  
**难度：** Level 4  
**Anchor：** Yes

### Prompt

> 一只白色兔子骑在一只黑色老虎背上。兔子右手提着一盏红色灯笼，灯笼正面清楚写着一个金色汉字“福”。它们正在穿过一座传统中式牌楼。画面中不要出现其他动物。

### Atomic Rubric

| 条件 | 分值 |
|---|---:|
| 出现且仅出现一只兔子 | 1 |
| 兔子为白色 | 1 |
| 出现且仅出现一只老虎 | 1 |
| 老虎主体呈黑色 | 1 |
| **兔子明确骑在老虎背上** | **2** |
| 兔子右手持红灯笼 | 1 |
| 灯笼正确写出“福” | 1 |
| 出现传统中式牌楼 | 1 |
| 无其他动物 | 1 |
| **Total** | **10** |

### 关键失败模式

- 老虎骑兔子
- 兔子与老虎只是并排出现
- 兔子颜色与老虎颜色互换
- “福”字乱码
- 牌楼被生成成普通西式拱门
